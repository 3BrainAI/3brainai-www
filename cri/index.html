Review-first boundary

Governed evidence, not raw imagery.

CRI complements site visits, technical advisers, internal controls and bank policy. It does not make autonomous credit decisions or replace professional assessment.

  • Human review
  • Traceable inputs
  • Explicit uncertainty
  • Audit trail

The gap is not image availability. The gap is review-ready evidence.

Banks and institutional owners already have reports, site visits, technical advisors and internal controls. The difficult part is comparable, time-stamped and traceable evidence between formal review points.

How it works

Earth Observation is one governed input source. Project context and operational data can also be used. CRI converts inputs into constrained evidence states and review-ready outputs.

Project context + governed input mediaOperational data, reports and Earth Observation as controlled inputs.
Site Understanding LayerStructured site and project context with traceable references.
Evidence EngineReason codes, confidence bands and uncertainty handling.
Evidence PackReview-ready artefact with status, provenance and audit trail.
Human reviewPrioritisation, escalation and accountable sign-off.

Validation and adoption path

Start in shadow mode alongside existing controls. If the workflow proves readable, useful and governable, define a paid pilot. Portfolio use follows only after agreed validation gates.
